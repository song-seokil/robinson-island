# 결정 대기와 결정 기록 (DECISIONS)

> 스펙([`GRAYBOX_SPEC.md`](GRAYBOX_SPEC.md))은 **확정된 규칙**만 담는다. 이 문서는 그 바깥을 다룬다:
> 아직 정해지지 않아 구축을 막는 것, 그리고 이미 내린 큰 결정의 근거.
> 여기 제안값은 전부 **미승인**이다. 사용자가 승인하면 스펙에 `[확정]`으로 옮기고, 스펙 §5와 `../../CHANGELOG.md`에 기록한다.

## 3. 결정을 옮기는 절차

1. 사용자가 제안값을 승인하거나 다른 값을 말한다.
2. `GRAYBOX_SPEC.md` §1에 `[확정]`으로 적고 §5에 버전을 올린다. §2/§4에서 해당 항목을 지운다.
3. 이 문서 §1에서 행을 지우고 §2에 한 줄 추가한다.
4. `../../CHANGELOG.md`에 `[설계]` 한 줄.
