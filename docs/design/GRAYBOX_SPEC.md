## 0. 목표

3D CoC형 장난감 병정 **기지 방어 + 자유 드롭 약탈** 게임의 핵심 루프를 회색 큐브 기준으로 검증한다.
목적은 재미의 완성도가 아니라 **한 판이 끝까지 돌아가는지** 확인하는 것이다.
아트는 이 검증과 **병행**한다(§1 아트 병행).

## 1. 확정 규칙

### 맵 [확정]

- 전체 **72×72**, 플레이 가능 영역 **64×64** (인셋 4).
- 산 1개 = **3×3 큐브를 차곡차곡 쌓아 만든 자연 산형**. 벽처럼 평면으로 세우지 않는다.
- 아래가 넓고 위로 갈수록 좁아지는 적층으로, 자연 산 실루엣을 만든다.
- 산의 형태는 **시드마다 랜덤**이다. 단일 봉우리·능선·피라미드형이 모두 나올 수 있다.
- 산은 **이용 불가 지형**이다. 통행·건설·파괴 불가. 벽과 같은 성질이나 파괴할 수 없다.
- 플레이 그라운드는 **평면**이다. 산의 높이는 표현일 뿐, 이동·사거리·건설 판정에 쓰지 않는다.
- **최소 평원 보장**: 건설·이동이 가능한 평지의 **최대 연결 요소**가 **1,944타일 이상**이어야 한다 (CoC 44×44와 같은 절대 칸수 = 플레이 64×64의 47.5%). 모양은 무관하고 칸수만 본다. 미달이면 시드를 재롤한다.
- 강 1개 + 도하 1~3개.
- 시작 지점은 **해안가**.
- 도하는 목재(나무 다리) 또는 석재(징검다리). 회색박스에서는 지형 표현만, 건설 비용 없음.
- 같은 시드 → 같은 섬.
- "강 안쪽" = 시작 지점과 같은 쪽.

### 경제 [확정]

- 자원 5종: **목재·석재·철·구리·석유**. 종류별 노드 1개 = 총 5개. 1×1~2×2.
- 무한 채집. 통행·건설·파괴 불가. 노드에 인접해야 채집, **노드당 동시 채집 1명**.
- 시작: 해안가에 **로빈슨 1명** + 목재 노드 1개. 로빈슨이 직접 목재를 채집한다.
- **로빈슨이 스킬북에서 채집꾼을 해금·제작**해 노드에 배치한다. 첫 해금은 목재꾼.
- 채집꾼 제작 = **스킬북 해제 → 채집꾼 제작**. 다음 시대 채집꾼의 재료는 **이전 시대 자원**에서 조달한다.
  석재꾼(석기)←목재 / 구리꾼(청동기)←석재 / 철꾼(철기)←구리 / 석유꾼(산업)←철. 수량 N은 미정.
- 채집꾼은 자원 전용 1:1 (목재꾼·채석공·구리공·제철공·석유공), 최대 5명.
- **로빈슨은 채집꾼에 포함되지 않는다.** 목재꾼 배치 후 채집에서 빠져 본진·방어로 전환한다.
- 경제 = 해금된 채집꾼 수 × 채집 속도. 인구 성장은 없다.

### 튜토리얼 / 자유 플레이 [확정]

- 첫 판(튜토리얼): 해안가에서 **목재부터 시작하는 수렵채집**. 해금 순서 고정.
- 2판 이후: 배치와 해금 순서를 플레이어에게 맡긴다.
- 맵 생성 최소 제약: **강 너머 최소 1종**.
- 회색박스에서는 튜토리얼을 고정 시드 1개 + IMGUI 안내로 축소 구현한다.

### 기지 [확정]

- 초반 보호(테스트): 시작 후 **120초 고정**. 측정용 상수이며 제품 값이 아니다.
- 초반 보호(제품): **초보자 보호 버블**. 기간·해제 조건은 미정, 회색박스 미구현.
- 건물 이동: **비용 없이 언제든** 가능. 단 전투 중에는 불가 (CoC 방식).
- 회색박스에서는 HQ 1개만 이동 가능. 벽은 테스트용으로 자동 생성한다.

### 약탈 [확정]

- 약탈은 **자유 드롭**. 플레이어가 유닛을 직접 배치한다 (CoC 방식).
- **배치 가능 범위는 최외곽 타일**이다. 그 안에서 자유롭게 드롭한다.
- **투입 후 유닛은 자율 행동**한다. 스스로 목표를 정하고 경로를 찾아 공격하며, 플레이어는 제어하지 않는다.
- 투입 지점에 따라 **여러 방향에서 진입할 수도, 한 곳에 집중할 수도** 있다.
- **1회 약탈 투입 상한은 100기**다. 보유 유닛 수는 이 상한과 별개이며, 사용자는 **여러 공격 덱**을 만들어 골라 실행한다.
- 배치 방식은 **두 가지를 병행**한다.
  - (a) **덱 투입 = 행군 대형**. 첫 줄부터 **일정 시간 간격으로 줄지어 입장**한다. 한 번에 전부 떨어뜨리지 않는다.
  - (b) **수동 드롭**. 보유 유닛 전체를 보여주고, 골라서 **터치할 때마다 1기씩** 떨어뜨리며 100기까지 채운다.
- 두 방식 모두 같은 100기 상한을 공유한다.
- 덱의 입장 간격과 열 수는 미정.

### 시대/파워 밴드 [확정]

- **시대 = 파워 밴드**다. 같은 시대 안에서 유닛·방어물의 성능 인플레이션을 억제하는 것이 목표다.
- 유닛과 방어 기물은 시대별로 계속 추가될 수 있다.
- **약탈은 동일 시대 내에서만** 매칭한다 (뉴비 보호).
- **진급은 플레이어의 의도로만** 일어난다. 자동·강제 진급은 없다.
- 진급 경로 = 채집꾼 제작. **다음 시대 채집꾼의 재료는 이전 시대 자원**에서 조달한다.
- 따라서 진급 재원은 약탈이 아니라 내부 채집이다. 약탈은 동일 시대 안의 자원 교환으로 한정된다.
- 강화도 같은 밴드 안에서 진행한다. 밴드 밖으로 성능이 튀지 않게 조절한다.
- 시대 내 밸런스 기준 수치는 미정.

### 아트 병행 [확정]

- 아트는 회색박스 이후가 아니라 **병행 트랙**이다. 무료 모델을 조금씩 채워 넣는다.
- 아트가 들어와도 **검증 기준은 회색박스**다. 판정·수치는 콜라이더와 논리 타일로 측정한다.
- 논리 크기(1타일 = 1유닛)·피벗·콜라이더는 아트와 분리해 고정한다. 아트는 **자식 비주얼**로만 붙인다.
- 회색박스와 아트가 **섞여 있어도 동작**해야 한다. 일부만 교체 가능해야 한다.
- 무료 모델은 라이선스를 기록한다 — `Assets/Art/CREDITS.md`에 파일·출처·라이선스·표기 여부.
- 스타일은 **토이/로우폴리**로 고정. 임포트 시 1타일 = 1m로 스케일을 정규화한다.
- 아트 때문에 밸런스나 판정을 바꾸지 않는다.

**프리팹 구조**

```
Unit (루트: 논리 크기·콜라이더·스크립트)
└─ Visual (자식: 아트 교체 슬롯)
```

- 루트는 이동·충돌·타겟팅에 쓰는 고정 크기. 아트를 바꿔도 변하지 않는다.
- 피벗은 바닥 중앙, 정면은 +Z.

**후보 소스** (건별 라이선스 확인)

| 소스 | 라이선스 | 특징 |
|---|---|---|
| Kenney | CC0 | 로우폴리 통일, 장난감 계열 |
| Quaternius | CC0 | 로우폴리 캐릭터·환경 |
| Poly Pizza | CC0/CC-BY 혼합 | 검색 편의, 건별 확인 |
| Sketchfab | CC0 필터 | 품질 편차, 리깅 확인 |

- 애니메이션은 팩 간 리그 호환이 되지 않는다. **공용 리그 1개** 또는 정지 모델로 시작한다.

## 2. 확인 필요 [가정 — 근거로 쓰지 말 것]

아래는 AI가 추정해 넣은 값이다. 맞으면 `[확정]`으로 올리고, 틀리면 지운다.

- 최외곽 링의 폭, 덱 입장 간격·열 수.
- 산의 층수·발자국·켜별 축소 비율(표현 값).
- 승리·패배 조건 (기존 "HQ 파괴 / 전멸·시간 초과"는 미확인).
- 유닛의 벽 처리: 우회 반경 8~12칸, breach 1~3타일, 타일당 2~3명.
- 유닛 AI: 5~10Hz, 타깃 고정 1.5초, 재평가 0.5~1초, 공유 플로우 필드.
- 성능 목표: 동시 100기(투입 상한)에서 데스크톱 60fps / 중급 Android 30fps.
- 지형 점유율 12% 이하, 산 점유 8×8~14×14(발자국 기준), 강 24~48×1~3, 플레이 영역 ±5%.
- 캐릭터 5~8 아키타입, 애니메이션 LOD 30/15/5Hz + 임포스터.
- 마일스톤과 기간, 20개 시드 검증.

## 4. 미결

- 최외곽 링 폭, 덱 입장 간격·열 수.
- 공격 덱: 개수, 구성 규칙, 유닛 보유 상한.
