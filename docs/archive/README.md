## 왜 폐기했는가 — 구 설계와 현재 설계의 차이

지형 모델 자체가 다르다. 이식하면 폐기한 가정이 되살아난다.

| 항목 | 구 설계 (폐기) | 현재 설계 (`../design/GRAYBOX_SPEC.md`) |
|---|---|---|
| 지형 | 연속 고도(Float) + 절벽 / 계단 | **메커니즘은 평면.** 높이는 산 표현에만 |
| 통행 | 폭 등급(WALK / CART / RIG), 입구 폭파 | 없음 |
| 산 | 메사 최대 2개, 평평한 정상 = 성 자리 | **3×3 큐브 적층, 자연 산형.** 통행 · 건설 · 파괴 불가 |
| 고지 | 사거리 +10%/타일 (최대 +25%) | 없음 |
| 자원 | 4종 + Lv1~10 성장 | 5종 고정 노드, 무한 |
| 생존 | 에너지 · 체온 · 요리 | 없음 |
| 전투 | 비동기 원정 120초, 타일 경로 계산기 | 자유 드롭 100기, 자율 행동, 실시간 |
| 엔진 | Phaser 3 / Three.js + Vite + Capacitor | Unity 6 |
