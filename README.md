## Unity 프로젝트

- 경로: `S:\02. 송서방\01. 로빈슨 크루소\unity\RobinsonGraybox`
- 엔진: Unity `6000.3.26f1`
- **C: 드라이브에 프로젝트/Library를 만들지 않는다.**

## 실행

1. Unity Hub에서 `S:\02. 송서방\01. 로빈슨 크루소\unity\RobinsonGraybox`를 연다.
2. `Assets/Scenes/SampleScene.unity`를 연다.
3. Play.

회색박스 M0~M2는 아직 구현되지 않았다. 자세한 순서는 `RESUME.md`를 참고한다.
