⛰️ 입체 목업 — “절벽 위 본거지” 설계 v1.5 · 개척(계단) 반영

숲·강·절벽이 높낮이로 보이는 디오라마 뷰 · 실제 구현은 2D 스프라이트 합성으로 이 느낌을 목표로 한다 (18-4)

✋ 밀어서 보기 — 좌우 = 돌리기 · 아래로 당기면 가까이 (위로 밀면 원래대로) · 핀치/휠 = 줌 0°

📖 어떤 순서로 짓나 (5-7)

  • 1일차 — 🏕️ 야영지: 모래·풀 위 · 🌿나뭇가지 수준
    → “절벽 위는 못 짓는다: 재료도 도구도 없다”
  • 석기 — 🛖 해변·평지 오두막: 돌 도끼·목재 확보 후
  • 청동기 — 🏰 절벽 위 본거지: 곡괭이 + 개척 필요
    → 석조 계단 ⛰️20 · 60초 (또는 경사 통로 — 재료 ×1.5·시간 ×2)

🪜 계단은 시설이다

  • 계단·통로가 없으면 쉘터 지정이 잠긴다 — “올라갈 길이 없다”
  • 계단에도 HP — 파괴되면 고립 → 보수 (13-5)
  • 병정도 결국 계단으로 올라온다 = 내가 정한 병목
  • 단, 🧗 기어오르기 병정은 계단을 무시하고 절벽을 탄다 (15-5)
    → 계단만 지키면 지는 이유 — 탑·함정을 절벽 위에도

🎨 아트 방침 (18-4 확장)

  • 탑다운 유지 + 높낮이: 절벽 단차(윗면+측면) · 계단 3/4 · 나무 캐노피 2~3겹 · 강은 물둑 단면
  • 스프라이트는 2D 합성 (8GB·모바일 — 실시간 3D 없음)
  • 그림자로 낙차: 절벽·바위는 키 큰 그림자
  • 밤: 창불·모닥불 주황 광원 + 달빛

① 1일차 — 모래 위 야영

재료·도구 없음 → 해변 모래밭부터. 절벽 위는 아직 꿈도 못 꾼다.

② 석기 — 평지 오두막

도구와 목재가 생기면 평지·해변에 제대로 된 거점을 세운다.

③ 청동기 — 절벽 위 본거지

곡괭이로 계단을 깎아야 그제서야 절벽 위가 내 쉘터가 된다.

⛰️ 절벽 = 윗면+측면(단차) · 계단은 3/4뷰 🌲 숲 = 캐노피 2~3겹 · 🌊 강 = 물둑 단면 + 물결 하이라이트 🪜 개척: 석조 계단 / 경사 통로 / 나무다리 — 파괴·보수 대상 (13-5) 빨간 점선 = 병정이 올라오는 유일한 길(병목) 🔄 밀어서 뷰 바꾸기 — 좌우 = 회전 · 상하 = 줌 (전체 일괄 회전 검증 · 실게임 UI는 정립 고정 — 18-4⑤) 실제 구현: 2D 스프라이트 합성(탑다운+높낮이) — 18-4
