## 0. 공통 규약
| 항목 | 규약 |
|---|---|
| 뷰 | **3/4 부감 47°** (우리 지형 렌더와 동일 — 스프라이트가 지면에 서 보여야 함) |
| 광 | **좌상단에서** 오는 부드러운 빛 · 짧고 부드러운 그림자(오른쪽 아래) |
| 배경 | 투명(PNG) · 그림자까지 포함된单个 스프라이트 |
| 팔레트 | 채도 높고 밝게 · 풀 `#5CC63A`~`#3E9E2A` · 바위 `#C9C2B8`~`#8A8278` · 모래 `#FBE3AE` · 물 `#4FD0D8`~`#0A3C8C` · 나무 `#A9703C` · 강조(수정/금) `#4FE8FF` / `#FFC53D` |
| 형상 | 둥글고 뭉툭(chunky) · 각진 저폴리 금지 · 진짜처럼 보일 만큼 디테일 |
| 크기 | 512×512 (캐릭터/건물 384×384 가능) · **발밑이 이미지 아래쪽 8% 지점** |

## 1. 프로프 (21종) — `public/props/<이름>.png`
이미 있는 저폴리 버전을 **같은 파일명으로 교체**하면 끝.

`n_tree` `n_palm` `n_bush` `n_berry` `n_rock` `n_ore` `n_tar` `n_crystal`
`b_campfire` `b_wall` `b_tower` `b_spikes` `b_hut` `b_raft` `b_chest`
`u_player` `u_sword` `u_archer` `u_bomber` `u_boss` `u_boar`

각각: 나무=통+겹잎, 야자수=기운 큰 잎, 바위=모서리 둥근+이끼, 수정=반짝이는 결정, 감시탑=돌 기둥+나무+지붕, 오두막=원기둥+뾰족 지붕 …

## 3. UI 아이콘 (무텍스트) — `public/icons/<이름>.png` (256×256, 투명, **굵은 실루엣**)
`icon_chat` `icon_axe` `icon_hammer` `icon_pickaxe` `icon_sword` `icon_raft`
`icon_campfire` `icon_flag` `icon_chest` `icon_target` `icon_map` `icon_pirate`

- 색 = 기능: 초록 가능 / 회색 잠김 / 금 강조 / 빨강 불가
- 첫 화면 3초 룰을 만족해야 함 (설명 없이도 뜻이 통함)

## 4. 우선순위 (효과 큰 순)
1. **캐릭터 5종**(로빈슨·검귀수·궁수·폭탄병·두목) — 게임의 표정
2. **건물 5종**(감시탑·팔리사드·오두막·모닥불·뗏목) — 전략의 눈
3. **자원 노드**(나무·바위·광맥·타르·수정) — 화면을 채운다
4. **지형 텍스처 5종** — 지면 밀도
5. **UI 아이콘** — 무텍스트화
